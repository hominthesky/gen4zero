# Security

Do not publish credentials, browser profiles, private recipe URLs, or unpublished artwork in an issue. For a vulnerability that could expose data or enable unintended code execution, use GitHub's private vulnerability reporting for `hominthesky/gen4zero` when available. If that channel is unavailable, open a minimal public issue that contains no exploit details and ask the maintainer for a private contact path.

Gen4Zero currently has no account, server runtime, analytics, upload, or remote generation. Its intended data boundary is documented in [`AGENTS.md`](./AGENTS.md) and [`docs/ENGINEERING.md`](./docs/ENGINEERING.md).
