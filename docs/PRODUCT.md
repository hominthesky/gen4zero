# Z4Zero Generative Studio｜产品定义 v0.1

## 一句话

一个把生成式艺术从“随机出图”变成“可调制、可组合、可复现、可交付、可策展”的浏览器原生创作工具。

## 为什么存在

多数生成图像产品把提示词当作唯一入口，把每次结果当作终点。Generative Studio 采用另一种创作模型：创作者先选择一套视觉系统，再改变规则、观察变化、保留 seed、组合图层，最后针对真实媒介导出。

它既是一件公开可玩的数字作品，也是一套 Z4Zero 持续研究设计、代码与视觉文化的工作台。

## 核心对象

### System

可独立运行的生成规则。首版包含：

- Vector Field：连续流线、噪声方向与运动轨迹。
- Orbital Bloom：参数曲线、玫瑰线与轨道叠合。
- Cellular Veil：节点、邻接关系与有机拓扑。
- Recursive Grid：递归分割、模块密度与结构节奏。
- Moiré Signal：相近频率的曲线叠合与视觉干涉。
- Particle Loom：横纵轨迹、贝塞尔曲线与编织关系。

后续系统可扩展至反应扩散、L-system、Voronoi、signed-distance field、shader feedback、字体与图像采样，但只有在浏览器性能、可控性与授权边界成立时进入正式版本。

### Recipe

作品的可复现配方：系统、seed、共享参数、色板、图层关系、混合方式、画布规格与时间点。Recipe 可以通过 URL 分享或以 JSON 保存，适合版本管理、复刻与二次创作。

### Output

输出不是附属下载，而是创作流程的一部分。画布预设围绕用途组织：

- Web hero：个人或产品网站首屏、全屏背景与响应式裁切。
- Full HD：演示、装置显示与横屏视频。
- TikTok / Reel：9:16 全屏竖向内容，并提供安全区参考。
- Feed：4:5、1:1 的常见社交画布。
- Social card：链接分享预览。
- Poster：A 系列纸张比例的印刷探索。

首版支持无损 PNG 与浏览器原生 WebM 短片；未来可增加序列帧、透明背景、SVG（适用于向量系统）、高质量 MP4 转码、循环点对齐与批量 seed 输出。

### Gallery

Gallery 有意分成两层：

- Curated selection：由 Z4Zero 选择并随网站版本公开发布的作品，是展览与品牌表达。
- My device：用户在本机保存的私人收藏，是工作过程，不上传、不要求账号。

未来公开社区 Gallery 不应直接建立在静态 Pages 上。若验证出真实需求，应独立设计投稿、署名、审核、内容许可与存储机制。

## 主要用户路径

1. 进入首屏，立即看到实时作品与关键控制，而不是先读营销介绍。
2. 选择系统，修改共享参数，精确输入或随机生成 seed。
3. 可选打开 Layer B，以不同系统和混合模式构成复合结果。
4. 选择用途预设，检查安全区，暂停到理想时刻。
5. 导出画面或短片；同时可保存/分享 Recipe，保证结果能被复刻。
6. 进入 Gallery 浏览策展作品，打开其 Recipe 继续改造。

## 产品原则

- System before image：规则先于单张结果。
- Curation after generation：生成提供空间，选择建立作品。
- Reproducible by default：seed 与配方是作品的一部分。
- Local-first：不为基础创作强迫登录、上传或联网。
- Useful canvases：从实际发布与展示场景倒推导出能力。
- Open for reconstruction：核心代码、配方格式与扩展入口应当可读。

## 开源与品牌结构

推荐源码作为独立公开仓库存在，使用 MIT 软件许可，便于 fork、教学和二次开发。产品名保留 Z4Zero 母品牌，推荐网址为 `studio.zzao.im`：它比个人主页子路径更独立，同时不必过早维护另一套品牌与域名。

仓库传播依靠可运行 demo、短 README、清楚的扩展入口、少依赖架构与作品配方。策展作品可以保留作者署名；代码许可与作品授权应分开表达。

## 路线图

### v0.1｜当前

六套系统、共享参数、双层组合、六套色板、用途预设、PNG、WebM、Recipe URL/JSON、公开与本地 Gallery。

### v0.2｜制作能力

透明背景、SVG/序列帧、精确循环、导出质量估计、自定义尺寸、参数锁定、seed 批量探索与性能分级。

### v0.3｜系统生态

插件式 renderer contract、社区系统模板、recipe schema 版本迁移、可访问性偏好、GPU shader 系统与离线 PWA。

### 条件性未来｜社区

只有在投稿需求持续出现后，才引入账号、作品托管、公开个人页、收藏与 remix lineage。需要先解决审核、版权、隐私、存储成本和滥用问题。
